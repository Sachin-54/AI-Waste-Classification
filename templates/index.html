ABOUT SORTSENSE

Smarter Waste. Cleaner Future.

SortSense is an AI-based waste classification system designed to make waste segregation simple and intelligent. Using a Support Vector Machine (SVM) model, the system analyzes uploaded waste images and identifies the appropriate waste category.

Instead of guessing where an item belongs, users can simply upload an image and receive an instant prediction, helping improve recycling and reduce improper waste disposal.
